01

The valley is the game

A village, a river, a forest, rice fields, a forgotten shrine, and a small hideaway. Gitakure is a game first.

GitHub activity is not a dashboard. It is the reason the orchard behind the shrine exists, why a particular villager moved here, and which paths are open.

02

Your year, planted

Every contribution is a planting. A quiet week is bare soil; a heavy one is a full paddy. The field only ever grows from real activity, so when the API is unreachable it stays exactly as it was.

03

Eighteen people live here

Villagers have names, routines and something to say. Each one is drawn from the same measured sheets the valley runs on.

    04

    Built from what is already there

    The valley is generated, not authored. That makes it cheap to grow and impossible to fake.

    Determinism

    World generation is a pure function of seed and world state. The seed is fixed for the valley, so the same save always rebuilds the same village.

    A sync only ever adds, through an explicit and idempotent step. Replaying one cannot double-apply it.

    Three ways to connect

    In increasing order of access.

    1. Public username No token, reads only public contribution data.
    2. Personal access token Supplied by you, held in memory for the session only, never written to local storage, IndexedDB or logs.
    3. GitHub App or OAuth Authorisation-code flow, handled by a backend you run yourself. No client secret is ever embedded in the bundle.

    Gitakure never requests repository write scope.

    05

    Run it locally

    Requires Bun 1.4 or newer. The asset build step measures the sprite boards first.

    Nothing is assumed about the sprites. Every frame is measured on the way in. 

    # install, measure sprites, run
bun install
bun run assets
bun run dev

    Serves on localhost:5173
